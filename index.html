How this dashboard works
No sign-in required. No IT setup needed. The dashboard fetches the shared Excel workbook via a CORS proxy (corsproxy.io), parses it in the browser with SheetJS, and builds the charts. Anyone with this page URL sees live data — no Microsoft account needed.

Dashboard reads live from Excel — no sign-in needed
This page fetches the shared Excel workbook via corsproxy.io (a free CORS proxy), parses it in the browser using SheetJS, and builds the charts from the Raw Data sheet. No Microsoft account required. No IT involvement. Works from any browser.
