Setup & connection guide
This dashboard reads live data from the Microsoft Forms → Excel workbook. Digital Leads submit activity via the Microsoft Form. This HTML file shows the data as charts and tables.
Current connection status
… Detecting…
1
Tier 1 — SharePoint session (no IT setup needed)
If this HTML file is hosted on your SharePoint site and opened while you're logged into Microsoft 365, it connects automatically using your existing session. No sign-in prompt, no app registration. This is the recommended starting point.
How to host it: upload the HTML file to the Digital Champions SharePoint site → Documents library → share the link as a Teams tab.
Site: https://weston.sharepoint.com/sites/WC_STU_24DigitalChampions
2
Tier 2 — Microsoft Graph API (needs one IT conversation)
If Tier 1 doesn't work in your environment, ask IT to register an app in Azure AD. They need to: create a new app registration, add a redirect URI pointing to where this file is hosted, and grant delegated permission for Sites.ReadWrite.All and User.Read. They then give you the Application (Client) ID.
Once you have the Client ID, replace YOUR_CLIENT_ID_HERE at the top of the script section and re-upload the file.
3
Tier 3 — Offline / localStorage fallback
If neither Tier 1 nor Tier 2 is available, the tool saves entries to this browser's localStorage. Digital Leads see their own entries locally. A mailto link lets them email entries to you directly. Data saved locally is not shared with other Digital Leads.
Data & privacy. All synced data is stored in the Weston College Microsoft 365 tenant (WC_STU_24DigitalChampions SharePoint site). Individual staff names are recorded as submitted. No learner personal data is collected. Processed under legitimate interests (quality assurance and professional development). UK GDPR compliant. Data controller: Weston College Group.
